# Implementation Plan: STRING PPI, Expression Atlas, and Reactome Integration

## Context

This plan addresses the user's request to add three new biological evidence sources to the drug repurposing application: STRING protein-protein interactions, Expression Atlas differential expression, and Reactome pathway overlap. These additions will strengthen mechanistic evidence for drug-disease associations beyond the current Open Targets, ChEMBL, UniProt, and OMIM data sources.

**Why these features matter:** Current scoring relies heavily on association strength and approval status, but lacks mechanistic validation. Adding network proximity (STRING), expression alignment (Expression Atlas), and pathway context (Reactome) provides biological justification for why a drug-target interaction could affect disease biology. This moves beyond correlation toward causation.

**Differentiation from Pharos:** Research confirms Pharos is a general target discovery platform (80+ data sources) focused on browsing the "druggable genome" — it does NOT specifically focus on drug repurposing, lacks computational scoring/ranking algorithms, and doesn't systematically match approved drugs to new diseases. Our app differs by: (1) active repurposing focus finding approved drugs for new indications, (2) algorithmic evidence-based ranking, (3) filtering to FDA-approved drugs (phase 4), (4) disease-input → ranked-candidates workflow, and **(5) user-configurable scoring weights** — a killer feature that lets researchers tune evidence priorities for their specific research goals. The new features will strengthen our unique value proposition.

**Key Innovations:**

1. **User-Configurable Weights:** Unlike competitors with fixed scoring algorithms, our app allows users to select from 4 preset profiles (Balanced, Clinical Focus, Mechanistic Discovery, Expression-Driven) or specify custom weights. This means:
   - **Clinical researchers** can prioritize FDA-approved drugs (Clinical profile: 70% clinical evidence)
   - **Academic researchers** can discover novel mechanisms (Mechanistic profile: 60% mechanistic evidence)
   - **Hypothesis-driven teams** can require strong dysregulation evidence (Expression profile: expression 30%)
   - **Advanced users** can fine-tune exact weights via sliders

2. **Intelligent Weight Redistribution:** When data sources are unavailable (API failure, missing data), their weights are **proportionally redistributed** to available sources. This ensures:
   - **Fair comparison** - Scores remain comparable even when different APIs succeeded
   - **No infrastructure penalty** - Candidate quality unaffected by API downtime
   - **Maintains 100-point scale** - Maximum score always achievable
   - **Confidence still tracks completeness** - 100/100 with 3/6 sources flagged as MEDIUM confidence

This flexibility addresses the core tension: different use cases need different evidence priorities, and infrastructure reliability shouldn't penalize candidate scores. Making weights transparent, configurable, and adaptive builds trust and empowers users.

**User decisions:**
- Keep 100-point scoring scale (redistribute weights, don't expand to 150)
- Use ChEMBL's `action_type` field (INHIBITOR/ACTIVATOR) for expression alignment
- Follow existing database pattern (add detail tables like omim_associations)
- Reduce target count if latency exceeds 60s
- **NEW: Allow users to configure scoring weights** (make app more flexible than competitors)
- **NEW: Redistribute unavailable weights** (if Expression Atlas fails, redistribute its 15pts to other sources equally)

## 1. Revised Scoring Algorithm (100-Point Scale with User-Configurable Weights)

### Default Weight Distribution

**Total: 100 points (redistributed)**

- **Open Targets**: 30 pts (reduced from 40) - disease-target association
- **ChEMBL**: 25 pts (reduced from 30) - drug approval status
- **STRING PPI**: 15 pts (NEW) - protein-protein interaction network proximity
- **Expression Atlas**: 15 pts (NEW) - differential expression + drug mechanism alignment
- **Reactome Pathways**: 10 pts (NEW) - pathway overlap between drug and disease
- **OMIM**: 5 pts (reduced from 10) - gene-disease validation

**Rationale for defaults:** Open Targets and ChEMBL remain primary signals (clinical validation), but mechanistic sources now contribute 40% of total score. This balances proven associations with biological plausibility. OMIM reduced due to redundancy with Open Targets. UniProt removed entirely — Reactome provides superior pathway data.

### User-Configurable Weighting Profiles

Users can select from preset profiles or create custom weights via the search interface:

**Profile 1: "Balanced" (Default)**
- Open Targets: 30, ChEMBL: 25, STRING: 15, Expression: 15, Reactome: 10, OMIM: 5
- Best for: General-purpose drug discovery, balanced clinical + mechanistic evidence

**Profile 2: "Clinical Focus"**
- Open Targets: 35, ChEMBL: 35, STRING: 10, Expression: 10, Reactome: 5, OMIM: 5
- Best for: Risk-averse researchers prioritizing approved drugs and validated targets

**Profile 3: "Mechanistic Discovery"**
- Open Targets: 20, ChEMBL: 15, STRING: 20, Expression: 25, Reactome: 15, OMIM: 5
- Best for: Exploratory research seeking novel mechanisms and understudied targets

**Profile 4: "Expression-Driven"**
- Open Targets: 20, ChEMBL: 20, STRING: 15, Expression: 30, Reactome: 10, OMIM: 5
- Best for: Hypothesis-driven research requiring dysregulated targets (expression as gatekeeper)

**Profile 5: "Custom"**
- User specifies exact weights (must sum to 100)
- Validation: Each weight 0-50, total = 100

### Updated Confidence Thresholds

- **HIGH**: total_score ≥ 70 AND data_completeness ≥ 0.67 (4/6 APIs succeeded)
- **MEDIUM**: total_score ≥ 40 AND data_completeness ≥ 0.50 (3/6 APIs succeeded)
- **LOW**: everything else

*Note: Confidence thresholds remain constant across profiles to maintain interpretability.*

### Weight Redistribution Strategy

**Problem:** If Expression Atlas API fails, a candidate with perfect scores in all other sources would only get 85/100 (losing 15 points), making scores incomparable across searches.

**Solution:** **Proportional weight redistribution** — when a source is unavailable, redistribute its weight to available sources proportionally.

**Example:**
```
Original weights: OT=30, ChEMBL=25, STRING=15, Expression=15, Reactome=10, OMIM=5
Expression Atlas fails (15pts unavailable)

Redistribution calculation:
- Available weight: 30+25+15+10+5 = 85
- Weight to redistribute: 15

Adjusted weights:
- OT: 30 + (15 × 30/85) = 30 + 5.29 = 35.29
- ChEMBL: 25 + (15 × 25/85) = 25 + 4.41 = 29.41
- STRING: 15 + (15 × 15/85) = 15 + 2.65 = 17.65
- Reactome: 10 + (15 × 10/85) = 10 + 1.76 = 11.76
- OMIM: 5 + (15 × 5/85) = 5 + 0.88 = 5.88
Total: 100 ✓

Now a candidate with perfect scores in available sources gets 100/100 (not 85/100)
```

**Benefits:**
1. **Fair comparison** - Scores comparable even when different APIs succeeded
2. **No API penalty** - Candidate quality unaffected by infrastructure failures
3. **Maintains 100-point scale** - Max score always achievable
4. **Proportional fairness** - Sources with higher weights receive more redistribution

**Confidence levels still reflect completeness** - A 100/100 score with only 3/6 APIs is marked MEDIUM confidence, signaling limited evidence despite high score.

**Important Implication:** With redistribution, `total_score` alone is no longer sufficient to assess quality. Always consider `data_completeness` alongside score. For example:
- Candidate A: 90/100 with 6/6 sources (HIGH confidence) → Strong comprehensive evidence
- Candidate B: 90/100 with 3/6 sources (MEDIUM confidence) → Good available evidence, but limited breadth

The confidence_level field automatically captures this nuance.

## 2. API Client Implementations

### 2.1 STRING PPI Network Client

**File:** `/backend/app/services/api_clients/string_db.py`

**Purpose:** Measure network proximity between drug targets and disease-associated proteins.

**API Endpoints:**
- Base URL: `https://string-db.org/api`
- Endpoint: `/json/network` - Get protein interaction network
- Parameters: `identifiers` (pipe-separated gene symbols), `species=9606` (human), `required_score=400` (medium confidence)

**Data Flow:**
1. Input: `target_gene` (e.g., "ACHE"), `disease_genes` (e.g., ["APP", "PSEN1", "MAPT"])
2. Query STRING for network including all genes
3. Calculate network distance: direct interaction = 0, shared partner = 1, two-hop = 2
4. Return: `{"direct_interactions": int, "network_distance": float, "interaction_score": float}`

**Scoring Logic:**
- Direct interaction with any disease protein: **15 pts**
- 1-hop distance (shared interaction partner): **10 pts**
- 2-hop distance: **5 pts**
- No connection within 2 hops: **0 pts**

**Key Implementation Details:**
- STRING API accepts up to 2000 identifiers, so batch all genes in single request
- Network distance = shortest path length (use BFS algorithm on returned edges)
- Weight by STRING combined_score (0.4-1.0 confidence)
- Handle case where target gene not in STRING (return empty dict)

### 2.2 Expression Atlas Client

**File:** `/backend/app/services/api_clients/expression_atlas.py`

**Purpose:** Validate if drug targets are dysregulated in disease tissue and if drug mechanism aligns with expression direction.

**API Endpoints:**
- Base URL: `https://www.ebi.ac.uk/gxa/api`
- Endpoint: `/query/results/differentialExpression` (or `/genes/{geneId}` as fallback)
- Parameters: `geneQuery={gene}`, `condition={disease}`, `organism=Homo sapiens`

**Data Flow:**
1. Input: `gene_symbol` (e.g., "APP"), `disease_context` (e.g., "Alzheimer"), `drug_action_type` (e.g., "INHIBITOR")
2. Query Expression Atlas for differential expression in disease
3. Calculate alignment: upregulated + inhibitor = positive, downregulated + activator = positive
4. Return: `{"fold_change": float, "p_value": float, "expression_level": str, "alignment_score": float}`

**Scoring Logic:**
- **Perfect alignment** (upregulated + inhibitor OR downregulated + activator) with p<0.05: **15 pts**
- **Moderate alignment** (FC between 1.5-2.0 OR p<0.1): **10 pts**
- **Weak alignment** (FC >1.2): **5 pts**
- **Misalignment** (upregulated + activator OR downregulated + inhibitor): **0 pts**
- **Unknown expression or mechanism**: **5 pts** (neutral/conservative)

**Key Implementation Details:**
- USER INSIGHT: Query ChEMBL mechanism endpoint to get `action_type` field (INHIBITOR, ACTIVATOR, AGONIST, ANTAGONIST, etc.)
- Map action types: INHIBITOR/ANTAGONIST → "inhibitor", ACTIVATOR/AGONIST → "activator"
- Expression Atlas may lack data for many diseases — gracefully return empty dict
- Tissue specificity bonus: +3pts if expression measured in disease-relevant tissue (brain for Alzheimer's, etc.)

### 2.3 Reactome Pathways Client

**File:** `/backend/app/services/api_clients/reactome.py`

**Purpose:** Measure pathway overlap between drug target pathways and disease-associated pathways.

**API Endpoints:**
- Base URL: `https://reactome.org/ContentService`
- Endpoint: `/data/pathways/low/entity/{identifier}` - Get pathways for gene
- Parameters: `identifier={UniProt_ID or gene symbol}`, `species=Homo sapiens`

**Data Flow:**
1. Input: `target_gene` (e.g., "ACHE"), `disease_genes` (e.g., ["APP", "PSEN1"])
2. Query Reactome for pathways containing target gene
3. Query Reactome for pathways containing disease genes
4. Calculate Jaccard similarity: |intersection| / |union|
5. Return: `{"shared_pathways": List[str], "pathway_similarity": float, "enriched_processes": List[str]}`

**Scoring Logic:**
- **High overlap** (Jaccard > 0.5): **10 pts**
- **Moderate overlap** (Jaccard 0.3-0.5): **7 pts**
- **Low overlap** (Jaccard 0.1-0.3): **4 pts**
- **No overlap**: **0 pts**

**Key Implementation Details:**
- Reactome provides hierarchical pathways — use low-level (specific) pathways only
- Cache pathway lookups per gene (reduce API calls)
- Handle case where gene not in Reactome (use UniProt pathways as fallback)
- Weight disease-relevant pathways higher (e.g., "Alzheimer disease" pathway for Alzheimer's)

### 5.1 Update calculate_total_score() signature to accept custom weights

```python
def calculate_total_score(
    self,
    open_targets_data: Optional[Dict] = None,
    chembl_data: Optional[Dict] = None,
    uniprot_data: Optional[Dict] = None,  # DEPRECATED: Will set to 0
    omim_data: Optional[List[Dict]] = None,
    string_data: Optional[Dict] = None,        # NEW
    expression_data: Optional[Dict] = None,    # NEW
    reactome_data: Optional[Dict] = None,      # NEW
    weights: Optional[Dict[str, float]] = None # NEW: User-configurable weights
) -> Dict[str, float]:
    """
    Calculate evidence-based score from multiple API sources.
    
    Args:
        weights: Optional dict with keys 'open_targets', 'chembl', 'string', 
                 'expression', 'reactome', 'omim'. If None, uses default weights.
    
    Default weights (sum to 100):
    - Open Targets: 30 pts
    - ChEMBL: 25 pts
    - STRING: 15 pts
    - Expression: 15 pts
    - Reactome: 10 pts
    - OMIM: 5 pts
    """
    # Load weights (defaults if not provided)
    if weights is None:
        weights = {
            'open_targets': 30.0,
            'chembl': 25.0,
            'string': 15.0,
            'expression': 15.0,
            'reactome': 10.0,
            'omim': 5.0
        }
    
    # Validate weights sum to 100
    total_weight = sum(weights.values())
    if abs(total_weight - 100.0) > 0.01:
        raise ValueError(f"Weights must sum to 100, got {total_weight}")
    
    # Calculate normalized scores (0-1 scale) from each source
    source_results = {
        'open_targets': (self._score_open_targets(open_targets_data) if open_targets_data else None, weights['open_targets']),
        'chembl': (self._score_chembl(chembl_data) if chembl_data else None, weights['chembl']),
        'string': (self._score_string(string_data) if string_data else None, weights['string']),
        'expression': (self._score_expression(expression_data) if expression_data else None, weights['expression']),
        'reactome': (self._score_reactome(reactome_data) if reactome_data else None, weights['reactome']),
        'omim': (self._score_omim(omim_data) if omim_data else None, weights['omim'])
    }
    
    # WEIGHT REDISTRIBUTION: If sources unavailable, redistribute weights to available sources
    available_sources = {k: v for k, v in source_results.items() if v[0] is not None}
    unavailable_sources = {k: v for k, v in source_results.items() if v[0] is None}
    
    # Calculate total weight to redistribute
    weight_to_redistribute = sum(v[1] for v in unavailable_sources.values())
    
    # Redistribute proportionally to available sources
    if weight_to_redistribute > 0 and len(available_sources) > 0:
        total_available_weight = sum(v[1] for v in available_sources.values())
        
        # Calculate adjusted weights (proportional redistribution)
        adjusted_weights = {}
        for source, (score, original_weight) in available_sources.items():
            proportion = original_weight / total_available_weight
            redistribution = weight_to_redistribute * proportion
            adjusted_weights[source] = original_weight + redistribution
        
        # Apply adjusted weights to available sources
        ot_score = (available_sources['open_targets'][0] * adjusted_weights['open_targets']) if 'open_targets' in available_sources else 0.0
        chembl_score = (available_sources['chembl'][0] * adjusted_weights['chembl']) if 'chembl' in available_sources else 0.0
        string_score = (available_sources['string'][0] * adjusted_weights['string']) if 'string' in available_sources else 0.0
        expression_score = (available_sources['expression'][0] * adjusted_weights['expression']) if 'expression' in available_sources else 0.0
        reactome_score = (available_sources['reactome'][0] * adjusted_weights['reactome']) if 'reactome' in available_sources else 0.0
        omim_score = (available_sources['omim'][0] * adjusted_weights['omim']) if 'omim' in available_sources else 0.0
    else:
        # No redistribution needed (all sources available or all failed)
        ot_score = source_results['open_targets'][0] * weights['open_targets'] if source_results['open_targets'][0] is not None else 0.0
        chembl_score = source_results['chembl'][0] * weights['chembl'] if source_results['chembl'][0] is not None else 0.0
        string_score = source_results['string'][0] * weights['string'] if source_results['string'][0] is not None else 0.0
        expression_score = source_results['expression'][0] * weights['expression'] if source_results['expression'][0] is not None else 0.0
        reactome_score = source_results['reactome'][0] * weights['reactome'] if source_results['reactome'][0] is not None else 0.0
        omim_score = source_results['omim'][0] * weights['omim'] if source_results['omim'][0] is not None else 0.0
    
    # UniProt deprecated - set to 0
    uniprot_score = 0.0
    
    total = ot_score + chembl_score + string_score + expression_score + reactome_score + omim_score
    
    # Calculate data completeness
    apis_succeeded = len(available_sources)
    data_completeness = apis_succeeded / 6.0
    
    # NOTE: With weight redistribution, total_score can still reach 100 even with missing sources
    # Confidence still considers completeness to flag cases with limited evidence
    confidence = self._determine_confidence(total, data_completeness)
    
    return {
        "open_targets_score": round(ot_score, 2),
        "chembl_score": round(chembl_score, 2),
        "uniprot_score": round(uniprot_score, 2),  # Always 0 now
        "omim_score": round(omim_score, 2),
        "string_score": round(string_score, 2),
        "expression_score": round(expression_score, 2),
        "reactome_score": round(reactome_score, 2),
        "total_score": round(total, 2),
        "data_completeness": round(data_completeness, 2),
        "confidence_level": confidence
    }
```

### 5.2 Update scoring methods to return normalized 0-1 scale

**IMPORTANT:** All `_score_*` methods now return normalized scores (0.0-1.0). The `calculate_total_score()` method applies user weights.

```python
def _score_open_targets(self, data: Dict) -> float:
    """
    Score Open Targets association (normalized 0-1 scale).
    Returns association_score directly (already 0-1).
    """
    association_score = data.get("association_score", 0.0)  # 0.0-1.0
    return association_score

def _score_chembl(self, data: Dict) -> float:
    """
    Score ChEMBL approval status (normalized 0-1 scale).
    Phase 4 (approved) = 1.0, Phase 3 = 0.7, Phase 2 = 0.4, Phase 1 = 0.2
    """
    max_phase = data.get("max_phase", 0)
    if max_phase == 4:
        return 1.0
    elif max_phase == 3:
        return 0.7
    elif max_phase == 2:
        return 0.4
    elif max_phase == 1:
        return 0.2
    return 0.0

def _score_omim(self, data: List[Dict]) -> float:
    """
    Score OMIM associations (normalized 0-1 scale).
    Caps at 2 associations = 1.0 (more gives diminishing returns).
    """
    if not data:
        return 0.0
    count = len(data)
    return min(count / 2.0, 1.0)
```

### 5.3 Add new scoring methods (normalized 0-1 scale)

```python
def _score_string(self, data: Dict) -> float:
    """
    Score STRING PPI network proximity (normalized 0-1 scale).
    
    Scoring:
    - Direct interaction: 1.0
    - 1-hop distance: 0.67
    - 2-hop distance: 0.33
    - No connection: 0.0
    """
    if not data:
        return 0.0
    
    direct_interactions = data.get("direct_interactions", 0)
    network_distance = data.get("network_distance", 999)
    
    if direct_interactions > 0:
        return 1.0
    elif network_distance == 1:
        return 0.67
    elif network_distance == 2:
        return 0.33
    return 0.0

def _score_expression(self, data: Dict) -> float:
    """
    Score expression alignment (normalized 0-1 scale).
    
    Scoring based on alignment between:
    - Gene expression (up/down/unchanged)
    - Drug mechanism (inhibitor/activator)
    
    Perfect alignment = upregulated + inhibitor OR downregulated + activator
    Returns alignment_score (0-1) adjusted for statistical significance.
    """
    if not data:
        return 0.33  # Conservative neutral score when unknown (1/3)
    
    alignment_score = data.get("alignment_score", 0.0)  # 0.0-1.0 from client
    p_value = data.get("p_value", 1.0)
    tissue_specific = data.get("tissue_specificity", False)
    
    # Base score from alignment
    base_score = alignment_score
    
    # Penalize if not statistically significant
    if p_value > 0.05:
        base_score *= 0.5
    
    # Bonus for tissue specificity (up to 20% boost)
    if tissue_specific:
        base_score = min(base_score * 1.2, 1.0)
    
    return round(base_score, 2)

def _score_reactome(self, data: Dict) -> float:
    """
    Score pathway overlap (normalized 0-1 scale).
    
    Uses Jaccard similarity of pathway sets:
    J = |intersection| / |union|
    
    Maps Jaccard to 0-1:
    - J > 0.5 → 1.0
    - J > 0.3 → 0.7
    - J > 0.1 → 0.4
    - J ≤ 0.1 → 0.0
    """
    if not data:
        return 0.0
    
    pathway_similarity = data.get("pathway_similarity", 0.0)  # Jaccard index 0.0-1.0
    
    if pathway_similarity > 0.5:
        return 1.0
    elif pathway_similarity > 0.3:
        return 0.7
    elif pathway_similarity > 0.1:
        return 0.4
    return 0.0

def _determine_confidence(self, total_score: float, data_completeness: float) -> str:
    """Determine confidence level (updated thresholds for 100-point scale)"""
    if total_score >= 70 and data_completeness >= 0.67:
        return "HIGH"
    elif total_score >= 40 and data_completeness >= 0.50:
        return "MEDIUM"
    else:
        return "LOW"
```

```python
async def _process_target(
    self, 
    target_data: Dict, 
    disease_genes: List[str],  # NEW
    disease_name: str          # NEW
) -> List[Dict[str, Any]]:
    gene_symbol = target_data["gene_symbol"]
    
    try:
        drugs_data = await self.chembl.get_drugs_for_target(gene_symbol)
    except Exception as e:
        print(f"ChEMBL error for {gene_symbol}: {e}")
        return []
    
    if not drugs_data:
        return []
    
    # Parallel async calls to all enrichment APIs
    omim_task = asyncio.create_task(
        self._safe_api_call(self.omim.get_gene_disease_associations, gene_symbol)
    )
    
    # NEW async calls
    string_task = asyncio.create_task(
        self._safe_api_call(
            self.string_db.get_protein_interactions, 
            gene_symbol, 
            disease_genes
        )
    )
    expression_task = asyncio.create_task(
        self._safe_api_call(
            self.expression_atlas.get_differential_expression, 
            gene_symbol, 
            disease_name
        )
    )
    reactome_task = asyncio.create_task(
        self._safe_api_call(
            self.reactome.get_pathway_overlap, 
            gene_symbol, 
            disease_genes
        )
    )
    
    # Gather all results (removed uniprot_task)
    omim_data, string_data, expression_data, reactome_data = await asyncio.gather(
        omim_task, 
        string_task, 
        expression_task, 
        reactome_task
    )
    
    candidates = []
    for drug_data in drugs_data:
        # NEW: Pass action_type to expression data for alignment calculation
        if expression_data:
            expression_data["drug_action_type"] = drug_data.get("action_type", "UNKNOWN")
        
        scores = self.scorer.calculate_total_score(
            open_targets_data=target_data,
            chembl_data=drug_data,
            uniprot_data=None,  # Deprecated
            omim_data=omim_data,
            string_data=string_data,
            expression_data=expression_data,
            reactome_data=reactome_data,
            weights=weights  # NEW: Pass through custom weights
        )
        
        candidate = {
            "drug_name": drug_data["drug_name"],
            "chembl_id": drug_data["chembl_id"],
            "target_gene": gene_symbol,
            "target_id": target_data["target_id"],
            "mechanism": drug_data.get("mechanism", "Unknown"),
            "action_type": drug_data.get("action_type", "UNKNOWN"),  # NEW
            **scores,
            "omim_associations": len(omim_data) if omim_data else 0,
            # NEW metadata
            "string_interactions": string_data.get("direct_interactions", 0) if string_data else 0,
            "network_distance": string_data.get("network_distance", 999) if string_data else 999,
            "expression_level": expression_data.get("expression_level", "unknown") if expression_data else "unknown",
            "expression_fold_change": expression_data.get("fold_change", None) if expression_data else None,
            "shared_pathways": reactome_data.get("shared_pathways", []) if reactome_data else [],
            "pathway_similarity": reactome_data.get("pathway_similarity", 0.0) if reactome_data else 0.0
        }
        
        candidates.append(candidate)
    
    return candidates
```

```python
# Preset weight profiles
WEIGHT_PROFILES = {
    'balanced': {'open_targets': 30, 'chembl': 25, 'string': 15, 'expression': 15, 'reactome': 10, 'omim': 5},
    'clinical': {'open_targets': 35, 'chembl': 35, 'string': 10, 'expression': 10, 'reactome': 5, 'omim': 5},
    'mechanistic': {'open_targets': 20, 'chembl': 15, 'string': 20, 'expression': 25, 'reactome': 15, 'omim': 5},
    'expression': {'open_targets': 20, 'chembl': 20, 'string': 15, 'expression': 30, 'reactome': 10, 'omim': 5},

@router.post("/search", response_model=SearchResponse)
async def search_drugs(
    request: SearchRequest,
    orchestrator: SearchOrchestrator = Depends(get_orchestrator)
):
    """
    Search for drug repurposing candidates with optional custom scoring weights.
    
    Can provide either:
    - `profile`: Use a preset weight profile ('balanced', 'clinical', 'mechanistic', 'expression')
    - `weights`: Specify exact weights (must sum to 100)
    - Neither: Uses default 'balanced' profile
    """
    # Determine which weights to use
    if request.weights:
        weights = request.weights.dict()
    elif request.profile:
        weights = WEIGHT_PROFILES[request.profile]
    else:
        weights = WEIGHT_PROFILES['balanced']  # Default

            disease_name=request.disease_name,
            weights=weights
        )
        
        return SearchResponse(
            disease_name=request.disease_name,
            total_candidates=len(candidates),
            weights_used=weights,
            candidates=candidates
        )
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))
```

```typescript
          candidate.expression_level === 'down' ? 'bg-blue-100 text-blue-800' :
          'bg-gray-100 text-gray-800'
        }`}>
          {candidate.expression_level.toUpperCase()}
          {candidate.expression_fold_change && 
            ` (${candidate.expression_fold_change.toFixed(1)}x)`}
        </span>
      ) : (
        <p className="text-sm text-gray-500">Not measured</p>
      )}
    </div>
    
    {/* Drug Mechanism */}
    <div>
      <span className="text-xs text-gray-600 block">Drug Action</span>
      <p className="text-sm font-semibold text-purple-700">
        {candidate.action_type || 'Unknown'}
      </p>
    </div>
    
    {/* Pathway Overlap */}
    <div>
      <span className="text-xs text-gray-600 block">Shared Pathways</span>
      {candidate.shared_pathways.length > 0 ? (
        <p className="text-sm font-semibold text-indigo-700">
          {candidate.shared_pathways.length} pathways
          <span className="text-xs text-gray-600 ml-1">
            ({Math.round(candidate.pathway_similarity * 100)}% overlap)
          </span>
        </p>
      ) : (
        <p className="text-sm text-gray-500">No overlap</p>
      )}
    </div>
  </div>
  
  {/* Show pathway names if available */}
  {candidate.shared_pathways.length > 0 && (
    <div className="mt-3">
      <details className="text-xs">
        <summary className="cursor-pointer text-gray-600 hover:text-gray-800">
          View shared pathways ({candidate.shared_pathways.length})
        </summary>
        <ul className="mt-2 ml-4 list-disc text-gray-700">
          {candidate.shared_pathways.slice(0, 5).map((pathway, idx) => (
            <li key={idx}>{pathway}</li>
          ))}
          {candidate.shared_pathways.length > 5 && (
            <li className="text-gray-500">+ {candidate.shared_pathways.length - 5} more</li>
          )}
        </ul>
      </details>
    </div>
  )}
</div>
```

## 11. Key Risks & Mitigation

### Risk 1: Expression Atlas Data Gaps
**Likelihood:** High | **Impact:** Medium

**Mitigation:** Expression Atlas has limited disease coverage. When data unavailable, return empty dict and give neutral 5pt score (not 0). Log missing data rates for future improvement.

### Risk 2: API Latency (>60s)
**Likelihood:** Medium | **Impact:** Medium

**Mitigation:** Already reduced targets from 10→8. If still slow: reduce to 6 targets, implement aggressive caching (24hr TTL), or add loading progress indicators.

### Risk 3: ChEMBL action_type Parsing
**Likelihood:** Medium | **Impact:** Medium

**Mitigation:** ChEMBL action_type field may have unexpected values. Create robust mapper with fallback to "UNKNOWN" → neutral score.

### Risk 4: STRING Network Complexity
**Likelihood:** Medium | **Impact:** Low

**Mitigation:** Limit to 2-hop neighborhood. Use STRING's pre-computed combined_score (don't calculate from scratch). Batch all genes in single API call.

### Risk 5: Score Distribution Shift
**Likelihood:** Medium | **Impact:** Medium (reduced with redistribution)

**Mitigation:** New sources may increase/decrease average scores unpredictably. Monitor score distributions post-deployment. Be ready to adjust weights in hotfix if needed. User-configurable weights mitigate this by allowing researchers to tune scoring for their specific use case. **Weight redistribution ensures scores remain on 0-100 scale regardless of API failures**, making comparisons more reliable.

### Risk 6: User Confusion with Custom Weights
**Likelihood:** Low | **Impact:** Low

**Mitigation:** Provide clear preset profiles with descriptions. Validate total=100 in real-time UI. Show "Weights used" in results so users understand what affected rankings. Include tooltips explaining each evidence source.
